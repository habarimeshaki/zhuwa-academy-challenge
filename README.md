# zhuwa-academy-challenge
repository for program that manages one rotating savings group

this is program about: a group of members each pay the same fixed amount every week. Each week the whole pot is paid to one member. Members receive the pot in the order they joined, one member per week.

I have made it by using JAVA.

by using Java with array list class I have managed to store resizable(variable) number of members with their specific details including name, his/her contribution, if she/ he has paid for specific week, and other additional detals.

I have achieved on this by using to classes one called management and other called member

through getter and setters method, I have also used to protect data to be modified with unverfied methods and validate data.

also I have been using built in functions mostly form array list to validate values.

by using give value, I have started by initialising class with fixed values and initial computations, and after, I added custom operations and vales from user inputs.
